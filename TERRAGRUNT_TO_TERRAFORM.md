# Terragrunt → Plain Terraform mapping

Condensed side-by-side for comparing [`aws-delphi`](../aws-delphi) (Terragrunt) with this repo (plain Terraform). Start with [README.md](./README.md) for the full Delos overview.

| Concern | Delphi (Terragrunt) | Delos (Terraform) |
|---|---|---|
| Shared account/env values | `account.hcl` + `root.hcl` merge | `environments/<env>/terraform.tfvars` + `-var-file` |
| Provider + tags | Generated by `root.hcl` | Checked-in `providers.tf` per stack |
| Remote state backend | Generated by `root.hcl` | `versions.tf` backend block + `backend.hcl` at `init` |
| Stack-specific settings | `inputs = { … }` in `terragrunt.hcl` | Values in that stack’s `main.tf` |
| Module call | `terraform { source = "…/tf-modules/…" }` | `module "…" { source = "…/tf-modules/…" }` |
| Cross-stack outputs | `dependency "x" { … }` → `dependency.x.outputs` | `data.terraform_remote_state.x.outputs` |
| Order-only dependency | `dependencies { paths = […] }` | Documented apply order (no unused remote state) |
| Layout | `aws-delphi-dev/us-east-1/<stack>/` | `live/<env>/us-east-1/<stack>/` |

## Shared config example

**Delphi** — gitignored `account.hcl` merged by Terragrunt:

```hcl
locals {
  env         = "dev"
  account_id  = "000000000000"
  aws_profile = "aws-delphi-dev"
}
```

**Delos** — committed placeholders in `environments/dev/terraform.tfvars`:

```hcl
env          = "dev"
account_id   = "000000000000"
aws_profile  = "aws-delos-dev"
landscape    = "delos"
# … route53_*, artifact_bucket, oidc_subjects, hosted_zone_name
```

## Cross-stack outputs example

**Delphi**

```hcl
dependency "vpc" {
  config_path = "../../vpc"
  mock_outputs = { isolated_subnet_ids = ["subnet-mock"] }
}

inputs = {
  subnet_ids = dependency.vpc.outputs.isolated_subnet_ids
}
```

**Delos**

```hcl
# remote_state.tf
data "terraform_remote_state" "vpc" {
  backend = "s3"
  config = {
    bucket  = local.remote_state_bucket
    key     = "live/${var.env}/us-east-1/vpc/terraform.tfstate"
    region  = var.region
    profile = var.aws_profile
  }
}

# main.tf
subnet_ids = data.terraform_remote_state.vpc.outputs.isolated_subnet_ids
```

Terragrunt can `plan` with `mock_outputs` before parents exist. Delos needs the parent stack **applied** first whenever `remote_state.tf` is present.

## How to run one stack

| Delphi | Delos |
|---|---|
| `cd …/vpc && terragrunt plan` | `./scripts/tf-stack.sh live/dev/us-east-1/vpc plan` |

Or manually:

```bash
cd live/dev/us-east-1/vpc
terraform init -backend-config=backend.hcl
terraform plan -var-file=../../../../environments/dev/terraform.tfvars
```

## Kos note

[`aws-kos`](../aws-kos) also uses `data.terraform_remote_state` and `tf-modules/`, but a Python orchestrator writes per-stack tfvars/backends and applies in `stacks.json` order. Delos keeps those files checked in and leaves ordering to you.
